# Tech stack

- [Next.js](https://nextjs.org) 16 (App Router)
- [React](https://react.dev) 19
- [Zustand](https://github.com/pmndrs/zustand) for state management
- [Tailwind CSS](https://tailwindcss.com) 4 for styling
- [opentype.js](https://opentype.js.org) for glyph outline extraction
- [jsPDF](https://github.com/parallax/jsPDF) + [svg2pdf.js](https://github.com/yWorks/svg2pdf.js) for PDF export
- [file-saver](https://github.com/eligrey/FileSaver.js) for downloads
- [lucide-react](https://lucide.dev) for icons
